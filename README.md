Item Manager (MERN Practice Project)

This is a practice MERN stack project built as part of my learning journey in full-stack web development. It includes a simple item management system along with a transparent login form UI for frontend practice.

The project is not fully implemented and is intended only for learning purposes, especially to understand React frontend, Node.js backend, API handling, and basic CRUD operations.

🎯 Purpose
Learn MERN stack development
Practice frontend + backend integration
Understand CRUD operations
Improve UI design (transparent login form)
Practice Git & GitHub workflow
🛠️ Tech Stack

React.js | Node.js | Express.js | MongoDB (if used) | HTML | CSS | JavaScript

⚠️ Status

This project is still in development and is not production-ready. It is only a practice project.
